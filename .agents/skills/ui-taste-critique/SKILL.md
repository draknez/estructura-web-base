# UI Taste & Visual Curation Skill

Pautas para lograr interfaces visualmente sofisticadas ("High-Taste UI"):

1. **Evitar la UI genérica ("AI Slop"):**
   - Evitar saturación excesiva de colores primarios y sombras negras pesadas (`shadow-2xl` opacas).
   - Preferir sombras con color ambiental difuso (ej: `shadow-lg shadow-teal-500/10`) y bordes sutiles semi-translúcidos (`border border-white/10`).

2. **Tipografía y Jerarquía:**
   - La jerarquía se establece primero con peso (`font-semibold` vs `font-normal`) y color (`text-slate-100` vs `text-slate-400`), antes de alterar drásticamente el tamaño de fuente.
   - Espacio en blanco ("negative space") generoso para permitir que los elementos respiren.

3. **Calm UI:**
   - Reducción activa de distracciones visuales. Los elementos interactivos deben descubrirse de forma natural y elegante.
